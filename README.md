Dinocomp is a dinosaur species comparator made for dinosaur lovers all alike. When you look at most online resources, they allow the user to look up individual species, but none of them have a tool that lets them compare multiple species sdie by side across their phyiscal stats, time periods, and geopgraphical range. Dinocomp was made to fix those gaps.

Features ✨
- Browse voew rendering all species cards with nname, period badge and esitmated length
- Filter sidebar correctly filter species based on selected inputs.
- Compare view render side by side table
- Live search input filters species in real time
- Responsive layout and works across all screen sizes.

Tech Stack 🛠️
- Framework: Typescript / Redux
- Styling: Tailwindcss
- Version Control: Github
- Testing: Jest / React Testing Library
